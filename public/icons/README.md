# OpenSea logo

The official OpenSea logomark ("Transparent White" version from
https://static.seadn.io/logos/Logomark-Transparent%20White.svg) lives
here as `opensea-logomark.svg`. `Footer.tsx` renders it via `<img>` at
`/icons/opensea-logomark.svg`, sized 20×20, with the white fill chosen
for the dark charcoal footer background.

Official brand blue, if needed elsewhere: `#2081E2` ("Sea Blue").
